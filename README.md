# Uplink Knowledge Base

Our Knowledge Base is built using [Starlight](https://starlight.astro.build/) on [Astro](https://astro.build/) and hosted on [Cloudflare Workers](https://workers.cloudflare.com/).

The Knowledge Base is live at: https://uplink.tech/knowledge-base/

If you would like to add or change anything, or even just fix a typo, please open a [Pull Request](https://github.com/uplinkhq/knowledge-base/pulls)!

## Development

```bash
npm install
npm run dev
```

## Deployment

```bash
npm run deploy
```
